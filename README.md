# 📱 Description 
`QvaPay` is a sdk write in Swift that work with the [QvaPay Api](https://qvapay.com/docs).

# 📦 Installation 

```swift
dependencies: [
    .package(url: "https://github.com/qvapay/client-swift.git", from: "1.0.0")
]
```

## 📱 Usage
```swift 
import QvaPay 

let qvapay = QvaPayApi.shared 
```
